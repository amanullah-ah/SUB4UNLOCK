# Sub4Unlock (Vercel + Upstash Redis)

Short links like `https://yourapp.vercel.app/aB3xK9`.

## Folder structure
- `public/index.html` = sirf home page (link banana). Isme unlock ka koi code nahi.
- `public/unlock-page/` = unlock page (`unlock.html`, `unlock.css`, `unlock.js`). Short link `/aB3xK9` ya `/l/aB3xK9` yahi page kholta hai (`vercel.json` rewrites).
- `public/css/base.css` = dono pages ka shared CSS (colors, logo + title, inputs, toasts, footer).
  `public/css/style.css` = sirf home page, `public/unlock-page/unlock.css` = sirf unlock page.
- `unlock.js` mein `DEMO = false` rakho (true karne par fake backend chalta hai, sirf preview ke liye).

## Domain
Production domain `https://aman-sub4unlock.vercel.app` hai (`lib/site.js` mein `DEFAULT_URL`). Generated links, robots.txt, sitemap.xml
aur canonical tag isi se bante hain. Preview deployments aur local dev apna host use karte hain. Domain badalna ho to
`PUBLIC_URL` env set karo aur `public/index.html` ke canonical/og:url update karo.

## Colors
Amber = agla action (Generate, Open & Verify, Unlock), cyan = links, green = done/unlocked. Tokens `public/css/base.css` ke `:root` mein hain.

## Deploy: GitHub + Vercel
1. Create a GitHub repo and push this whole folder (keep the structure: `api/`, `lib/`, `public/`, `vercel.json`).
2. Go to vercel.com -> **Add New -> Project** -> import the repo -> **Deploy** (no build settings needed).
3. In the Vercel project open the **Storage** tab -> create/connect an **Upstash Redis** database
   (free plan is enough) and connect it to this project. It adds the env vars
   `KV_REST_API_URL` and `KV_REST_API_TOKEN` automatically.
4. **Redeploy** (Deployments -> ... -> Redeploy) so the env vars take effect. Done.

## Even shorter links
Buy a short domain (e.g. `s4u.link`) and add it in Vercel -> Settings -> Domains.
Links become `s4u.link/aB3xK9`. If you want to force the base URL, set env `PUBLIC_URL=https://s4u.link`.

## Optional env vars
- `SECRET`   long random string used to sign verification tokens (auto-derived from the Redis token if unset)
- `PUBLIC_URL`  force the base URL used in generated links

## Run locally
    node server.js        # http://localhost:3000, stores data in ./data (no Redis needed)

## Notes
- Link banane ke liye kam se kam ek platform ya password zaroori hai (frontend aur backend dono check karte hain).
- The real destination URL is only returned after all steps are verified (and password is correct).
- Passwords are scrypt-hashed; wrong attempts are rate limited.
- No website can truly confirm a follow without each platform's OAuth/API; this is a "visit + wait 6s + confirm" gate.

## SEO, robots.txt and sitemap.xml
- `public/index.html` has the SEO tags (title, description, Open Graph, Twitter card, JSON-LD) for **AMAN SUB4UNLOCK**.
- `/robots.txt` and `/sitemap.xml` are generated by `api/robots.js` and `api/sitemap.js` from your own domain
  (or from `PUBLIC_URL` if you set it), so nothing needs editing when you change the domain.
- Only the home page is in the sitemap. Locked links (`/aB3xK9`) are private: they are sent with
  `X-Robots-Tag: noindex, nofollow` (see `vercel.json`) and are not listed anywhere.
- After deploying, add your site in Google Search Console and submit `https://YOUR-DOMAIN/sitemap.xml`.
- When you change the home page, update `LASTMOD` in `lib/site.js`.
